# 2026-11-25: a grid's spacing is dimensioned to the millimetre (VEW-46)

## For people

- A structural grid's spacings are drawn to the millimetre: 7.425 m reads 7.425, not 7.43, so the
  spacings add up to the overall figure (VEW-46).

## For agents

- The pictures write a grid dimension in metres with three decimals. No new code in the record.
