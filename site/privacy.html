Privacy policy (draft)

Last drafted 23 November 2026. This page describes how Grid is designed to work; it is a draft, not legal advice, and the owner must review it before it is published. Where the hosted server does not exist yet, the hosted sections describe the intended design (the report's “Option B”).

Grid on your computer

The grid command and the local tool server (npx -y ongrid mcp) run on your computer. They read and write only files inside the project folder you choose. They send nothing anywhere: the problem-report tool (grid_report_problem) drafts an issue and shows it to you, and you decide whether to file it. Grid does not collect usage data.

The hosted server (when it is live)

  • Stateless. The hosted server keeps no state between calls.
  • No accounts. There is no sign-in, no profile and no payment.
  • Your plan is sent with each call and is not stored. The plan travels in the request, is read to answer it and is not written to disk or kept after the answer is sent.
  • No analytics are planned for this site or the server. If that changes, this page will say what is measured before it is.
  • Operational logs. A host normally records technical request data (time, address, status, size) to keep the service running. This draft does not yet say how long such logs are kept: the owner must fill in the retention period and the host's name.

Your AI assistant

When you use Grid through an assistant (Claude, ChatGPT, Cursor and others), the assistant's own provider receives what you write and what Grid returns, under that provider's own policy. Grid does not control that.

Names inside plans

Room names and ids go into every export and sheet and travel with the plan file. Do not put a person's name in a room's name or id; who sits where belongs in a separate occupancy file that no export carries.

This website

This site is static pages with no scripts, no cookies set by us and no third-party fonts or trackers.

Contact

Questions about this policy: open an issue at https://github.com/ongrid-arch/grid/issues. See also support.
