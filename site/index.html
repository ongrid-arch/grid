Grid (ongrid): floor plans for AI agents

Reads, measures, checks, draws and changes floor plans kept in one plan file. Describe a home or a building to your agent and it draws, measures, checks and changes the plan with Grid. Homeowners, architects, builders and students can use it.

Status, 23 November 2026. Grid is not published yet: the npm package, the hosted server and the directory listings wait on the owner. Lines marked “available once published” will work only then. Until then, build Grid from a copy of the repository.

What Grid does

  • Keeps one structured plan file (walls, rooms and openings) as the source of truth, stored in metres and shown in each person's own units: metres, centimetres, millimetres, or feet and inches.
  • Writes a plan rooms first: you name the rooms with their inside sizes and neighbours, and the doors and windows by the rooms they join; Grid works out the walls.
  • Reads, measures, draws (2D and 3D), checks and changes the plan through 33 tools named grid_…, served over MCP (the Model Context Protocol).
  • Exports DXF, IFC, OBJ and GLB, and writes an A3 PDF sheet.

General guidance, not your local rules

Every report Grid writes carries that label, and no message says a plan complies or is approved. A clean check only means Grid's checks found nothing. Figures from building codes carry their source and a status; a figure an AI found stays marked as such until a named person has checked it.

Try it

  1. npm ci && npm run build in a copy of the repository, then alias grid="node $PWD/packages/cli/dist/grid.mjs".
  2. grid init my-home && cd my-home makes a project folder with an empty plan.json.
  3. Write the rooms below in plan.rooms, run grid write plan.rooms, then grid check and grid draw --out plan.svg.
room living  "Living room" living  4.0 x 3.5 at 0,0
room kitchen "Kitchen"     kitchen 2.5 x 3.5 east of living
door front in living south, centred, 0.9 wide, opens in
opening pass between living and kitchen, centred, 0.9 wide
window w-kitchen in kitchen east, centred, 1.2 wide

Use Grid in your assistant

One line starts Grid's tool server for any agent that runs tools on your computer: npx -y ongrid mcp. Step-by-step pages cover Claude Code, Codex, Cursor, VS Code and Copilot CLI, Gemini CLI, Claude Desktop and Cowork, and (once a hosted server is live) Grok, Perplexity and Le Chat.
