Use Grid in Gemini CLI

Grid runs on your computer as a tool server that Gemini CLI starts with one line, npx -y ongrid mcp.

Status, 23 November 2026. Grid is not published yet: the npm package, the hosted server and the directory listings wait on the owner. Lines marked “available once published” will work only then. Until then, build Grid from a copy of the repository.

Install

Available once published to npm. Grid's install listing has no ready-made line for Gemini CLI yet. Any agent that can start a standard-input MCP server can run Grid: add a server named grid whose command is npx -y ongrid mcp (command npx, arguments -y ongrid mcp), following Gemini CLI's own documentation for adding MCP servers. The exact Gemini CLI syntax has not been tried against Grid.

A Gemini CLI extension (a gemini-extension.json file in the public repository) is a possible later step and is not done.

Using Grid once it is connected

Ask your agent for a plan in your own words, for example “write a two-bedroom flat, 7 m by 8 m, with the entrance on the south side”. The agent reads the guide for agents, keeps what you asked for in a brief, writes the plan rooms first and runs grid_check after each change.

General guidance, not your local rules

Every report carries that label. Grid's checks are general guidance on the drawing and on code figures with their sources; they never say a plan complies or is approved.
