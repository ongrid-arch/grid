Use Grid in Grok

Available once the hosted server is live. The URL below is a placeholder: Grid's hosted server does not exist yet, and nothing here works today. Grok takes a public remote MCP server: add a custom connector and paste the URL.

Steps, once it is live

  1. Open Grok's settings for custom connectors (its own help pages say where; the steps differ by plan and may change).
  2. Add a remote MCP server and paste this URL: 
    https://ongrid.example/mcp
  3. Choose no sign-in: the hosted design is stateless with no accounts, and your plan is sent with each call and is not stored (privacy).
  4. Ask for a plan in your own words.

Because the hosted server has no project folder, its tools take the plan itself as input. Until then, use a coding agent: all assistants.
