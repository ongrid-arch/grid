Support (draft)

Grid is an open-source project. Support is through GitHub issues: https://github.com/ongrid-arch/grid/issues. There is no phone line, no email desk and no guaranteed response time. The owner must confirm a contact address and a response promise before this page is published.

Before you write

  • Read the guide for agents and the commands.
  • Check the installation page for your assistant: Use Grid in….

Reporting a problem

If a Grid tool's answer looks wrong, an agent can call grid_report_problem: it drafts an issue for you. Grid sends nothing; read the draft, remove anything private and file it yourself. Please include the Grid version, your assistant and the rooms text or plan file that shows the problem.

What Grid's answers are

General guidance, not your local rules

Grid gives general guidance on the drawing and on figures from building codes, each with its source and a status. It is not advice on your local rules, and no report says a plan complies or is approved. Check your own local requirements with the authority that applies to your project.

Security

Report a security problem privately through the repository's security advisories rather than a public issue: https://github.com/ongrid-arch/grid/security/advisories/new.
